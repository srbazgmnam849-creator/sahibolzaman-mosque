# سامانه جامع مدیریت مسجد صاحب‌الزمان 🕌

نسخه استقرارشده روی **GitHub Pages** با تازه‌سازی خودکار هر ۵ ساعت از طریق **GitHub Actions**.

## 🔗 لینک‌ها
- **سایت (لینک اصلی):** `https://srbazgmnam849-creator.github.io/sahibolzaman-mosque/`
- **مخزن کد:** `https://github.com/srbazgmnam849-creator/sahibolzaman-mosque`

## ⚙️ سازوکارها
| قابلیت | شرح |
|---|---|
| تازه‌سازی خودکار | Workflow «Auto Refresh» هر ۵ ساعت (cron `0 */5 * * *`) اجرا می‌شود، مهر زمانی را به‌روز می‌کند و Pages را دوباره Deploy می‌کند. |
| ذخیره‌سازی امن دیتابیس | دیتابیس SQLite درون مرورگر شما (IndexedDB) با رمزنگاری **AES-GCM** ذخیره می‌شود و با ریفرش یا بستن مرورگر از بین نمی‌رود. |
| پشتیبان‌گیری | از منوی «تنظیمات و پشتیبان‌گیری» می‌توانید فایل پشتیبان رمزنگاری‌شده (‎.mszbak‎) یا SQL خالص بگیرید و بازگردانید. |
| امانت‌داری داده | داده‌ها فقط روی دستگاه خودتان است؛ هیچ داده‌ای روی سرور ارسال نمی‌شود. |

## 🔑 حساب‌های آزمایشی
۱۵ حساب نقش‌محور (امام جماعت، دبیر، هیئت مدیره، مالی، فرهنگی، پشتیبانی، آموزش، خواهران، بسیج برادران، بسیج خواهران، هیات، خیریه، مربی، عضو، مدیر رسانه) داخل صفحه ورود قابل مشاهده است. **این داده‌ها آزمایشی هستند** و در محیط عملیاتی باید تغییر کنند.

## 📝 نکته مهم
پس از استقرار، توکن دسترسی (PAT) که در گفتگو اشتراک گذاشته شده را از تنظیمات گیت‌هاب **باطل (Revoke)** کنید.
